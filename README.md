# 格温 · 角色试演室

可复用的 2D 网页演员小样。一个格温、一张电竞休息室背景，分别演出两段台词：

- **Take A**：「Bin 哥，冠军皮肤选我好不好？」——说话、歪头、眨眼。
- **Take B**：「那一定要好好考虑我呀。」——抬剪刀、说话、微笑、放下。

网页首页是演员试演室；四幅分镜的 20 秒初版保留在 [comic.html](comic.html)。

## 怎样体验

1. 选 Take A 或 Take B，点「演出这段」。两段各约 6.2 秒，包括动作前后留白。
2. 单独点击「说话」「眨眼」「歪头」「抬剪刀」。说话过程中可以再叠加动作。
3. 打开「显示关节」检查肩、肘、颈与握持点；打开「展开部件」查看独立部件，也能继续试演。
4. 支持暂停、进度拖动、重演、字幕、静音、全屏和手机布局。空格播放/暂停，左右键跳转半秒。

两段共用同一个 SVG 演员实例、10 个绘制部件、程序口型与同一背景。切换台词只换音轨和动作数据，不重新生图，也不调用浏览器 TTS 或运行时生成 API。

## 本地运行与导出

无需安装前端依赖。需要 Python 3（开发服务器）与 Node.js（测试/构建）。

```sh
npm run dev
# http://localhost:5715/
npm test
npm run build
npm run export
```

- `dist/` 是可静态托管的完整网站。
- `dist/gwen-actor.html` 是画面、配音、逻辑均内嵌的演员单文件版。
- `dist/gwen-short.html` 是原分镜初版的单文件版。

单文件版可下载后用普通浏览器打开。所有站点资源采用相对路径，兼容 GitHub Pages 仓库子目录。GitHub Pages 发布选择 `main` 分支和 `/ (root)`。

## 演员、动作、场景分离

| 文件 | 职责 |
| --- | --- |
| `assets/gwen/atlas.png` | 新绘制的透明部件图集 |
| `assets/gwen/rig.json` | 各部件窗口、缩放、锚点与关节坐标 |
| `actor-rig.js` | SVG 装配、头部和眼睛层、肩肘链、剪刀握持与程序嘴型 |
| `actor-motion.js` | 可复用的眨眼、歪头、抬剪刀与音频口型采样 |
| `takes.json` | 两段台词、音轨、拼音、说话区间与动作编排 |
| `assets/gwen/lounge.png` | 独立空场景，人物不在背景里 |
| `actor-lab.js` | 演出调度、手动动作叠加、声音与控制台 |

部件图集使用 SVG `viewBox` 窗口读取，背景和角色从源素材起就独立。头部绕颈转动，双马尾跟随头部并轻微摆动；上臂绕肩、前臂绕肘转动；剪刀绑定前臂上的握持点，腕部进行反向补偿，让剪刀保持竖直。

自动演出以 `audio.currentTime` 为时钟，暂停与跳转可以重建同一姿态。手动动作使用自己的短时间轴，因此可以在说话中叠加，也可以单独演示。动作结束回到静止姿态，换台词会清理上段的动作状态。

口型从音轨每 25ms 的音量包络与估算拼音节奏得到开口、圆唇、展唇和闭唇参数，用 SVG 绘制口腔、牙齿、舌头和唇线。不是逐音素强制对齐。

系统的「减少动态效果」会关闭自动呼吸、头发摆动、眨眼与肢体动作，保留配音、字幕和口型；用户主动点击的单次动作仍可体验。

## 素材制作与消耗

本次小样新增 **一次透明部件图集生成、一次空场景生成**。两段声音从仓库已有配音中复用，没有新增 TTS 合成调用。网页播放和两段之间的切换不调用生成模型。

这描述的是实际制作步骤，不能换算成平台账号扣除的具体额度或费用。后续新增剧本可以复用演员和动作；新增身体角度、服装或复杂手势仍需要补素材和适配。

重新提取这两段音轨与包络（FFmpeg、NumPy）：

```sh
python tools/prepare-rehearsal.py
```

原 20 秒音轨仍可用 `tools/prepare-voice.py` 与 AISHELL-3 VITS 模型重新生成，具体音色为女声 6、男声 10。见 [素材和参考](docs/CREDITS.md)。

## 验证

```sh
npm test
# 先启动开发服务器并执行 build/export，再运行：
python tests/actor_browser.py
# 保留的分镜初版回归检查：
python tests/browser.py
```

浏览器检查需要 Python Playwright 和 Chromium，可用 `CHROMIUM_PATH`、`TEST_URL`、`TEST_OUTPUT` 覆盖默认值。覆盖真实配音、两段完整播放、部件独立动作、握持点无漂移、切换台词无新增图片请求、手机布局和单文件版无外部资源请求。截图保存在忽略的 `test-results/`。

URL 加 `?capture` 会启用调试 API `window.__gwen`，包含 `selectTake(index)`、`seek(seconds)`、`freeze(seconds)`、`trigger('blink'|'tilt'|'raise'|'speak')`、`poseAt(seconds)`、`audio` 与 `rig`。

## 当前边界

这是固定正面角度的半身分层演员，不含新生成视频、完整三维转身或任意姿态。身体没有腿部，默认构图裁到腰部；展开模式显示素材边界。大幅动作的肩肘接缝、握手细节和近似嘴型仍有打磨空间。当前只有预制的两段台词，没有接入实时 TTS 或自由剧本输入。

格温为《英雄联盟》角色。本项目是同人虚构演出；配音采用通用合成音色，未克隆选手、真人或官方角色配音演员的声音。初版中的 S16 战绩与冠军皮肤设定仅为用户剧本，不代表实际赛事结果或选手言论。
